# Student Score Prediction

## Project Overview

This project demonstrates a basic machine learning workflow for predicting exam scores based on the number of hours a student studies.

## Problem Statement

Can we predict a student's exam score using their study hours?

## Dataset

The dataset contains:

* Hours Studied
* Exam Score

## Machine Learning Approach

We used:

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Linear Regression

## Workflow

1. Loaded the dataset
2. Explored the data
3. Visualized the relationship
4. Split the data into training and testing sets
5. Trained a Linear Regression model
6. Generated predictions
7. Evaluated the model

## Results

Add the actual MAE, RMSE and R² obtained from the model.

## Conclusion

The model demonstrates how study hours can be used to predict exam performance in this sample dataset.
